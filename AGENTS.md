# Agent routing

Two different jobs bring an AI coding agent into this repository. Pick yours:

- **Installing Something for the person you're talking to** (the landing page
  or README sent them here): follow [docs/AGENT_SETUP.md](docs/AGENT_SETUP.md).
  The contributor rules don't apply to you — but one rule of the runbook is
  absolute: never ask the person to paste secrets into the chat.
- **Changing this repository** (fixing, building, refactoring): follow
  [CLAUDE.md](CLAUDE.md) — everything committed in English, never leak a
  client, branch first, docs before main.
