# Task templates & priority definitions

## Task entry format

```
### Task Title
**Owner:** Name · **Priority:** High/Medium/Low · **Deadline:** YYYY-MM-DD or TBD

Context paragraph — what this is, why it matters, what's needed to complete it.
Include blockers, dependencies, relevant file paths. Write for someone reading in 3 weeks.
```

When marking Done, add `**Completed:** YYYY-MM-DD` to the entry.

## Priority definitions

| Priority | Criteria |
|---|---|
| High | Blocks other work, deadline within 2 weeks, or direct revenue/legal impact |
| Medium | Important but not urgent — can wait 2–4 weeks |
| Low | Nice to have, no deadline pressure |

## Section ordering inside Tasks.md

```
# Tasks

## In Progress
<active tasks>

## Backlog
<not yet started>

## Done
<completed, newest first>
```

In Progress comes first because it's what the user opens the file for. Done at the bottom is a log, not a focus area.
