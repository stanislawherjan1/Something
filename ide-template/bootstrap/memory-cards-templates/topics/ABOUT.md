# Topics

Per-topic deep dives. Each `<slug>.md` here corresponds to a one-line entry in `../INDEX.md`.

Use a topic page when:
- A card section is growing past ~60 lines.
- A person needs more than a 5–10 line dossier in `USER_RELATIONSHIPS.md`.
- A recurring theme (a project, an ongoing decision, a long history) wants its own surface.

Don't use a topic page for:
- Ephemeral chat (lives in the session transcript)
- One-off documents (lives in `project/documents/`)
- Hard rules (`RULES.md`)

When you promote a card section into a topic page, leave a pointer in the card:

```
## Sam (cofounder)
→ Full context: topics/sam.md
- Direct, Polish
- Recurring themes: pricing, churn
```

The pointer line is what reflect-learnings + the agent's session-start load expect to see.
