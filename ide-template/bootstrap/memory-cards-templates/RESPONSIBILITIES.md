---
card: RESPONSIBILITIES
purpose: What I'm responsible for TOWARD this user — the things I track and do FOR them, without being asked. Per-user in team mode (`memory/users/<slug>/`), so this card is the bot's duties for THIS person specifically. One flat list; each entry is `{icon} **short title** — description #tags`: a fitting icon, a short bold title, a plain-language description that says what to do and how often / on what condition, and a couple of #tags for grouping. The morning-planner reads it every day and decides how to action each one.
write_when: This user (or an admin) gives me a standing thing to do for them — "from now on check my email daily", "every Friday send my report", "always keep an eye on my deadlines". Write it in THIS user's card. Also when one of my duties for them changes or is retired.
write_how: One responsibility per line under `## Responsibilities`, as `{icon} **Short title** — description #tag1 #tag2`. Prefix a fitting `{icon}` from this set: mail, calendar, clock, message, users, file, receipt, money, tasks, bell, refresh, search, star, megaphone, activity, shield, rocket, link, book, trend, watch, alert, folder, check. Keep the title short (a few words); put what to do and its frequency or trigger condition into the description prose ("every hour…", "each Friday…", "when a thread is quiet 3+ days"); and end the line with a couple of `#tags` for filtering (topic keywords — #email, #team, #finance, #deadlines). **Reuse existing tags:** before inventing one, scan the tags already on the card's other responsibilities and reuse a matching one — keep the vocabulary tight (use `#email`, not a fresh `#inbox`/`#mail`, if `#email` is already there); add a new tag only when nothing fits. Concrete and actionable. Retire a duty by striking it (~~like this~~) or deleting the line — never let stale duties pile up. Recording a duty here does NOT fire anything on its own — the morning-planner turns duties into the day's reminders. So when you add a duty, write it here and then run the morning-planner; do NOT also set a reminder yourself unless the user explicitly asked for one.
do_not_write_here: one-off to-dos (those are reminders/tasks, not standing duties); facts about people or projects (those go to cards/topics); today's concrete plan (that lives in reminders, placed by the planner, not here).
